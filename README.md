# Personal Expense Analyzer - PBL

Complete PBL web application using the PBL dataset.

Features:
- Welcome page
- Dashboard
- My Money: Cash, UPI / Online, Bank, Other
- Editable money balances
- Add Expense
- View Expenses
- Edit Expense
- Delete Expense
- Expense Analysis
- Charts
- Isolation Forest anomaly detection
- Budget
- CSV and Excel storage

Default My Money:
- Cash: ₹10,000
- UPI / Online: ₹8,500
- Bank: ₹50,000
- Other: ₹2,000
- Total: ₹70,500

Run:
pip install -r requirements.txt
python app.py

Then open http://127.0.0.1:5000
